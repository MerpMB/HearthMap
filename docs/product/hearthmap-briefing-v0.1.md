### ชั้นความจริง (Truth hierarchy) ที่ใช้ตลอดเอกสาร

| **DECISION / RECOMMENDATION** | การตัดสินใจหรือคำแนะนำ | **ยังไม่มี** ในเอกสารนี้ |

## 3. วิธีอ่าน HearthMap: สี่ขั้นของการตัดสินใจ

```flow
Region — ภูมิภาค (Regional Screening) ◀ HearthMap แข็งแรงที่สุดตรงนี้
Candidate area — พื้นที่ผู้สมัคร (Candidate-zone Comparison) ◀ เตรียมพร้อมบางส่วน
Real listings / parcels — แปลงที่ประกาศขายจริง (Parcel Shortlist) ◀ ยังไม่ได้สร้าง
Field verification — ตรวจสอบในพื้นที่ (Pre-purchase Verification) ◀ ยังไม่ได้สร้าง
Purchase decision — การตัดสินใจซื้อ ◀ เป็นของครอบครัว ไม่ใช่ของระบบ
```

| ขั้น | คำถามที่ตอบ | สถานะปัจจุบัน |
|---|---|---|
| **Regional Screening** | พื้นที่กว้าง ๆ ส่วนไหนมีหลักฐานอะไร และส่วนไหนยังไม่ทราบ | มีชั้นข้อมูลภัย การเดินทาง การตั้งถิ่นฐาน บริการ อุตสาหกรรม |
| **Candidate-zone Comparison** | เมื่อมีพื้นที่ผู้สมัคร เปรียบเทียบกันอย่างไร | หลักฐานหลายส่วนพร้อมในรูป context/proxy แต่ **ยังไม่มี candidate zone** |
| **Parcel Shortlist** | แปลงจริงแปลงไหนควรไปดู | ยังไม่มีข้อมูลตลาดที่ดินหรือแปลงจริง |
| **Pre-purchase Verification** | แปลงนี้ผ่านเงื่อนไข MUST จริงหรือไม่ | ต้องตรวจที่แปลงและในพื้นที่ (ไฟฟ้า ไฟเบอร์ น้ำ ทางเข้าออก) |

## 5. ฐานหลักฐานภัยธรรมชาติ (Hazard foundation)

**คำถาม: มีหลักฐานภัยธรรมชาติประเภทใดอยู่แล้วบ้าง?** · ชั้นความจริง: DERIVED EVIDENCE (M1E provisional)

![ฐานข้อมูลภัยธรรมชาติ](../../outputs/briefing/maps/01-hazard-foundation.png)

สี่แผงแยกกัน **ไม่มีคะแนนภัยรวม (no scalar hazard score)**:

| ตระกูลหลักฐาน | สิ่งที่เห็น (สัดส่วนพื้นที่ AOI) |
|---|---|
| น้ำท่วม | หลักฐาน STRONG ≈ 3.5% ของพื้นที่ กระจุกในที่ราบลุ่มแม่น้ำของเชียงราย (แม่สาย–เชียงแสน–เชียงราย–พาน) และแอ่งพะเยา/ดอกคำใต้ |
| ดินถล่ม / ภูมิประเทศ | STRONG ≈ 25% ของพื้นที่ (เทือกเขา); **NOT_ASSESSED ≈ 14%** แสดงเป็นสีเทา ไม่ใช่ "ไม่มีภัย" |
| แผ่นดินไหว | ≈ 54% ของพื้นที่อยู่ในโซนที่ต้อง **ออกแบบรับแรงแผ่นดินไหว** (SEISMIC_DESIGN_REQUIRED) |
| การกระทำเชิงภูมิภาค (รวม) | CONTINUE_SEARCH ≈ 69%, WITH_AVOIDANCE_CAUTION ≈ 8%, DEPRIORITIZE_REGION ≈ 20%, UNRESOLVED ≈ 2.5% |

หลักสองข้อที่ต้องจำ:

- **hazard severity ≠ land-selection consequence** — ความรุนแรงของภัยไม่ได้แปลตรงเป็นผลต่อการเลือกที่ดิน M1E แปลงหลักฐานเป็น *การกระทำ* (ค้นหาต่อ, ระวัง, ลดความสำคัญ, ตรวจที่แปลง, ออกแบบโครงสร้าง)
- **seismic mitigation ≠ regional avoidance** — โซนแผ่นดินไหวนำไปสู่ "ต้องออกแบบโครงสร้าง" ไม่ใช่ "หลีกเลี่ยงพื้นที่" จึงใช้สีม่วง แยกจากโทนสีของการหลีกเลี่ยง
- สีอ่อน (CONTINUE_SEARCH หรือ "ไม่มีหลักฐานที่ trigger") **ไม่ได้แปลว่าปลอดภัยหรือดี** แปลว่าหลักฐานที่มีไม่ได้กระตุ้นการกระทำใด

## 6. ถนนและการเข้าถึง (Roads and accessibility)

ชั้นความจริง: DERIVED EVIDENCE · โครงข่าย BASELINE_DRIVE_TIME แช่แข็ง (fingerprint `5c35e98882c3ac62`), snap 1 กม., จุดวิเคราะห์ตามสัญญา canonical AOI analysis point (M2D.1e)

![ถนนและการเข้าถึง](../../outputs/briefing/maps/02-routing-accessibility.png)

| การถ่วงน้ำหนัก | สัดส่วนที่อยู่ในเซลล์ UNRESOLVED |
|---|---|
| จำนวนเซลล์ | **43.0%** (69,631 จาก 162,073) |
| พื้นที่ | **42.6%** (0.4265; เอกสาร M2D ปัดเป็น 42.7%) |
| ประชากรแบบจำลอง (WorldPop 2025, **MODELLED**, AOI-clipped) | **1.61%** (≈ 53,800 จาก 3,341,405) |
| สิ่งปลูกสร้าง (GHSL built-up m²) | **0.57%** |

> **Large geographic coverage gaps do not mean large settlement gaps.**
> ช่องว่างเชิงภูมิศาสตร์ที่ใหญ่ ไม่ได้แปลว่ามีช่องว่างของการตั้งถิ่นฐานที่ใหญ่

- UNRESOLVED = ไม่มีถนนที่เชื่อมกับโครงข่าย (OSM primary → unclassified) ภายใน 1 กม. — ค่าเป็น "ยังไม่ทราบ" ไม่เคยเป็น 0 นาที และไม่ใช้ระยะเส้นตรงแทน
- เซลล์ที่ยังไม่ทราบส่วนใหญ่เป็นภูเขาและป่าที่มีการตั้งถิ่นฐานเบาบาง (มัธยฐาน 0 คน, 0 m² สิ่งปลูกสร้าง)
- สีม่วงบนแผนที่ (≈ 1,500 เซลล์) คือเซลล์ที่ยังไม่ทราบแต่มีสัญญาณการตั้งถิ่นฐาน ≥ มัธยฐานของเซลล์ที่คำนวณได้ — เป็น *display class เพื่อการทบทวน* ไม่ใช่เกณฑ์ ส่วนใหญ่อยู่ห่างโครงข่าย 1–2 กม. (แม่ฟ้าหลวง อมก๋อย ดอยเต่า แม่แจ่ม จอมทอง แม่สรวย)
- ยังไม่มีการเปลี่ยนนโยบาย routing ใด ๆ

| โรงพยาบาลระดับสูง / ศูนย์ส่งต่อ | 65.5 นาที | 44.3% (อีก ≈ 20,700 เซลล์มีถนนแต่ไม่ถึงภายในขอบเขตค้นหา 120 นาที) |

หมายเหตุ: ภาพ M2A เดิมที่แสดงว่าโรงพยาบาลระดับสูง "UNRESOLVED 100%" เป็นภาพเก่า **ไม่ใช่ความจริงปัจจุบัน** — artifact ปัจจุบันคำนวณเส้นทางได้ใน 44.3% ของเซลล์

**ข้อจำกัด — การศึกษา**
- ทะเบียนสถานศึกษาเป็น **STALE / PARTIAL** (DOPA 2021 + การจำแนกระดับ OBEC 2020; ประมาณครึ่งหนึ่งของโรงเรียนมีการจำแนกที่เป็นทางการ) ทะเบียนปัจจุบันของ MOE เข้าถึงไม่ได้
- ประวัติการจำแนกระดับ: มัธยมต้นและปลายยังแยกกันไม่ได้ในระดับภูมิภาค (pooled)
- ปลายทางจำกัดเฉพาะ 3 จังหวัด (**BOUNDARY_LIMITED**) — เซลล์ริมขอบอาจเข้าถึงโรงเรียนในจังหวัดข้างเคียงได้เร็วกว่าที่แสดง

**ข้อจำกัด — สาธารณสุข**
- แหล่งข้อมูลหลักคือจุดสถานพยาบาลสาธารณะของ MoPH (644 แห่ง) เน้นของรัฐ
- **ระดับโรงพยาบาล ≠ ขีดความสามารถ** — ยังไม่มีหลักฐานเรื่องห้องฉุกเฉิน ICU หรือ trauma
- ปลายทางจำกัดเฉพาะ 3 จังหวัดเช่นกัน

> เวลาที่สั้นกว่า **ไม่ได้ดีกว่าโดยอัตโนมัติ** และไม่บอกคุณภาพโรงเรียนหรือโรงพยาบาล เป็นบริบทการเดินทางเท่านั้น

## 8. การตั้งถิ่นฐานและรูปแบบสิ่งปลูกสร้าง (Settlement and built form)

ชั้นความจริง: OBSERVED (GHSL, ดาวเทียม) + MODELLED (WorldPop) → ใช้เป็น PROXY / CONTEXT

![การตั้งถิ่นฐานและสิ่งปลูกสร้าง](../../outputs/briefing/maps/04-settlement-built-form.png)

> **population intensity ≠ built form ≠ peacefulness**
> ความหนาแน่นประชากร ≠ ความหนาแน่นสิ่งปลูกสร้าง ≠ ความสงบ

- **WorldPop R2025A** เป็นค่าประมาณแบบจำลอง (MODELLED_POPULATION_ESTIMATE, alpha) ไม่ใช่สำมะโน รวม ≈ 3.34 ล้านคนใน AOI
- **GHS-BUILT-S 2020** เป็นพื้นที่สิ่งปลูกสร้างจากดาวเทียม (≈ 330 km² ใน AOI) ไม่ใช่จำนวนอาคาร
- WorldPop ใช้ชั้นข้อมูล GHSL เป็นตัวแปรร่วม จึง **PARTLY DEPENDENT** — ความสอดคล้องกัน (rank correlation 0.87) **ไม่ใช่การยืนยันอิสระ**

รูปแบบที่มองเห็นได้ (เชิงพรรณนา):
- **แกนเมืองหลัก**: แอ่งเชียงใหม่ (เมือง–สารภี–สันทราย–หางดง), เมืองเชียงราย, เมืองพะเยา
- **แนวการตั้งถิ่นฐานในหุบเขา**: แอ่งฝาง–แม่อาย–ไชยปราการ, ที่ราบเชียงราย–แม่จัน–แม่สาย, แนวพาน–แม่ใจ–พะเยา–ดอกคำใต้, แนวจอมทอง–ฮอดตามลำน้ำปิง
- **พื้นที่สูง/ป่าที่เบาบาง**: ตะวันตกของเชียงใหม่ (แม่แจ่ม กัลยาณิวัฒนา อมก๋อย) และขอบตะวันออกของพะเยา
- **การตั้งถิ่นฐานความหนาแน่นปานกลาง**: หุบเขาขนาดเล็กจำนวนมาก (เช่น แม่สรวย เวียงป่าเป้า เชียงคำ ปง)

ยังไม่มีนิยามเชิงตัวเลขของ "dense urban core" (ไม่ได้รับอนุญาตให้ตีความ) — แผงเทียบเมืองอ้างอิงอยู่ในชุด QA `outputs/m2d-review/urban-core-calibration-panels.png`

## 10. อุตสาหกรรม เหมือง และบริบทความรำคาญ

ชั้นความจริง: OBSERVED (ทะเบียน) แต่ใช้เป็น PROXY / CONTEXT เท่านั้น — สามความละเอียดเชิงพื้นที่ที่ต่างกัน

![อุตสาหกรรม เหมือง และบริบทความรำคาญ](../../outputs/briefing/maps/06-industry-mining-context.png)

| ป้าย | แหล่ง | สิ่งที่บอก | สิ่งที่ไม่บอก |
|---|---|---|---|
| **ADMINISTRATIVE CONTEXT** | ทะเบียนโรงงาน DIW (2,061 รายการใน AOI, นอกนิคมอุตสาหกรรม) | จำนวนรายการต่อตำบล | พิกัดโรงงาน, สถานะการดำเนินงาน (ทุกแถวเป็น UNKNOWN) |
| **REGISTER STATUS** | DPIM ใบอนุญาตโม่บดหิน (46 รายการ) และประทานบัตร (88 รายการรวมที่หมดอายุ) | สถานะทะเบียน วันที่ ตำบล | พิกัด, การดำเนินงานปัจจุบัน |
| **LEGACY CONTEXT** | DPIM snapshot ปี 2016 | ประวัติประทานบัตร | ความจริงปัจจุบัน |
| **LOCATED OSM CONTEXT** | OSM (212 landuse=industrial, 46 works, 37 quarry, 3 อื่น ๆ) | ตำแหน่งที่มีผู้ทำแผนที่ไว้ | สถานะการดำเนินงาน, ความครบถ้วน (OSM ทำแผนที่อุตสาหกรรมไม่ครบ) |

- มีโรงงานโม่บดหินสถานะ "เปิดการ" ใน 11 ตำบล และประทานบัตรสถานะยังไม่หมดอายุใน 12 ตำบล
- ทั้งตำบลได้สีเดียวกันโดยเจตนา เพื่อไม่ให้ดูเหมือนรู้ตำแหน่งโรงงาน

> **factory presence ≠ nuisance confirmed** · **licence status ≠ current operation** · **tambon evidence ≠ exact facility location**

หลักฐานนี้มีประโยชน์ในการชี้ว่า *ตำบลใดควรสอบถามหรือไปดูเพิ่ม* เมื่อมีพื้นที่ผู้สมัคร แต่ไม่ได้ยืนยันว่ามีเสียง ฝุ่น หรือกลิ่น ไม่มี buffer หรือการตัดพื้นที่ใด ๆ

## 11. สาธารณูปโภคและความจริงระดับแปลง (Utilities and parcel-stage truth)

> **Some of the most important MUST requirements are intentionally deferred to parcel verification rather than guessed regionally.**
> ความต้องการระดับ MUST ที่สำคัญที่สุดบางข้อ ถูกเลื่อนไปตรวจที่แปลงจริงโดยเจตนา แทนที่จะเดาจากข้อมูลภูมิภาค

| ความต้องการ | ระดับ | หลักฐานระดับภูมิภาคตอนนี้ | ต้องยืนยันที่ไหน |
|---|---|---|---|
| ไฟฟ้า grid | MUST, ก่อนซื้อ | ไม่มีแหล่งข้อมูลที่อ่านด้วยเครื่องได้ (`REVIEW_CONTEXT_ONLY`) | สอบถาม กฟภ. (PEA) สำหรับแปลงนั้น |
| น้ำ — กปภ. (PWA) | ไม่บังคับ | ไม่มีขอบเขตพื้นที่บริการ | สอบถามสาขา กปภ. |
| น้ำ — ประปาท้องถิ่น/หมู่บ้าน | ยอมรับได้ถ้าเชื่อถือได้ | ไม่มีหลักฐาน | ถาม อบต./เทศบาล, คณะกรรมการหมู่บ้าน, เพื่อนบ้าน (ฤดูแล้ง) |
| น้ำบาดาล / บ่อ | ยอมรับได้ถ้าตรวจสอบแล้ว | ไม่มีหลักฐาน (อาจเพิ่ม aquifer context เป็น proxy) | ปริมาณ ความลึก คุณภาพ ใบอนุญาตเจาะ |
| Fixed fiber | MUST, ก่อนซื้อ | **ไม่มีชั้นข้อมูลไฟเบอร์ระดับภูมิภาคที่เชื่อถือได้** (`DEFERRED_NO_SPATIAL_COVERAGE_DATA`) | ผู้ให้บริการยืนยันกับที่อยู่ของแปลง |
| ทางเข้าออกตามกฎหมาย | MUST | เป็นข้อเท็จจริงของแปลง | โฉนด สถานะทางสาธารณะ ภาระจำยอม |
| ทางเข้าใช้ได้ทุกฤดู | MUST | ไม่มีหลักฐานฤดูฝน | ตรวจถนนช่วงฤดูฝน ถามคนในพื้นที่ |
| ผิวทาง (ทางลูกรังยอมรับได้) | ยอมรับได้ | ไม่มีหลักฐาน | ตรวจสภาพจริง |

## 12. ความครบถ้วนของหลักฐาน (Evidence completeness)

![สถานะของหลักฐาน](../../outputs/briefing/maps/07-evidence-state.png)

ตารางนี้สร้างตรงจาก `config/family-evaluability.yaml` (M2C + M2D.1 + M2D.1e) หมวดที่ใช้:

| หมวด | สถานะในระบบ | ความหมาย |
|---|---|---|
| **KNOWN** | READY | ประเมินได้เต็มที่ — **ปัจจุบันยังไม่มีรายการใด** |
| **KNOWN WITH LIMITATIONS** | READY_WITH_LIMITATIONS | ใช้ได้พร้อมข้อจำกัดที่แสดงไว้ (เช่น เวลาไปโรงพยาบาล, บริการรายองค์ประกอบ) |
| **PARTIAL** | PARTIAL | มีหลักฐานบางส่วน/เก่า (เช่น การศึกษา, การเชื่อมโครงข่ายถนน, ภูมิประเทศ) |
| **PROXY ONLY** | PROXY_ONLY | มีเพียงสัญญาณแทน (เช่น ความสงบ, ความรำคาญในระดับ candidate zone) |

| **PARCEL VERIFICATION REQUIRED** | PARCEL / FIELD_VERIFICATION_ONLY | ตอบได้ที่แปลงจริงหรือในพื้นที่เท่านั้น |

ที่ขั้น Regional Screening: KNOWN WITH LIMITATIONS 4 รายการ, PARTIAL 6, PROXY ONLY 1, UNRESOLVED/NOT EVALUABLE 15, BLOCKED BY SOURCE GAP 1, NOT USED (by design) 2

> หมวดเหล่านี้ **ไม่ถูกรวมเป็นคะแนนความเชื่อมั่น** ข้อมูลที่ขาดไม่เคยถูกตีความว่า "ผ่าน" (policy `VERIFY_NOT_PASS`)

## 13. สิ่งที่ HearthMap ตอบได้แล้ว

- แนวการตั้งถิ่นฐานหลักอยู่ที่ไหน
- พื้นที่กว้าง ๆ ส่วนไหนมีการตั้งถิ่นฐานเบาบาง
- พื้นที่ส่วนไหนเชื่อมโครงข่ายถนนพอสำหรับการวิเคราะห์เส้นทาง และส่วนไหนยังไม่ทราบ
- พื้นที่ส่วนไหนดูใกล้/ไกลจากโรงเรียน โรงพยาบาล และกลุ่มบริการ (เป็นบริบท ไม่ใช่คุณภาพ)
- ตำบลใดมีบริบทอุตสาหกรรม/เหมืองที่ควรตรวจสอบต่อในอนาคต
- พื้นที่กว้าง ๆ ส่วนไหนมีการกระทำด้านภัยระดับภูมิภาคที่หนักกว่า
- พื้นที่ใดข้อมูลน้อยและควรคงสถานะ UNRESOLVED ไว้

HearthMap **ยังตอบไม่ได้** ว่า "ควรซื้อที่ไหน"

## 14. สิ่งที่ยังตอบไม่ได้ (เพื่อความโปร่งใส)

- อำเภอที่ดีที่สุด
- แปลงที่ดีที่สุด
- ความเหมาะสมโดยรวมสำหรับครอบครัว
- ราคาตลาดที่ดินจริงในปัจจุบัน
- โฉนด / สิทธิ์ทางเข้าออกตามกฎหมายของแปลง
- การเชื่อมต่อไฟฟ้า grid จริง
- ไฟเบอร์ถึงแปลงใดแปลงหนึ่งหรือไม่
- ปริมาณและคุณภาพน้ำ
- คุณภาพโรงเรียน
- ขีดความสามารถทางการแพทย์ทั้งหมด (ER/ICU/trauma)
- ผลกระทบจากความรำคาญที่แท้จริง (เสียง ฝุ่น กลิ่น)
- นิยามสุดท้ายของ "บริการในเมือง"

## 15. เส้นทางสู่คำตอบสุดท้าย

```flow
CURRENT — Regional evidence stack (ชั้นหลักฐานระดับภูมิภาค) ◀ อยู่ตรงนี้
NEXT — Land-market evidence + remaining decision semantics (ราคาที่ดิน + นิยามที่ยังค้าง)
THEN — Candidate-zone engine (สร้างพื้นที่ผู้สมัคร)
THEN — Real parcel ingestion (นำเข้าแปลงที่ประกาศขายจริง)
THEN — Parcel due diligence (ตรวจสอบรายแปลง)
FINAL — Small number of parcels worth visiting / verifying (แปลงจำนวนน้อยที่คุ้มค่าจะไปดู)
```

คำตอบสุดท้ายของระบบจะมีรูปแบบว่า:

> **"พื้นที่ไหนคุ้มค่าพอที่จะไปดูต่อ และเพราะอะไร"**

ไม่ใช่ "AI บอกว่านี่คือที่ดินที่ดีที่สุด"

## 17. ภูมิศาสตร์อ้างอิง (Named geography — REFERENCE AREAS)

ชื่อด้านล่างเป็น **REFERENCE AREAS** เพื่อการวางทิศทาง ไม่ใช่ candidate zone ไม่ได้เรียงตามความเหมาะสม (เรียงตามจังหวัดและทิศ) ตัวเลขเป็นสถิติเชิงพรรณนาของอำเภอ (ประชากรเป็น MODELLED; เวลาไปโรงพยาบาลเป็นมัธยฐานถ่วงประชากรเฉพาะเซลล์ที่มีเส้นทาง)

| จังหวัด | Reference area / อำเภอ | หมายเหตุหลักฐานปัจจุบัน |
|---|---|---|
| เชียงใหม่ | **Chiang Mai urban basin** — เมืองเชียงใหม่ | แกนเมืองหนาแน่นที่สุดใน AOI (≈ 2,460 คน/km² แบบจำลอง, built-up ≈ 25 km²); ถนนเชื่อม ≈ 88% ของพื้นที่; อยู่ในโซนออกแบบรับแรงแผ่นดินไหวทั้งอำเภอ |
| เชียงใหม่ | **Fang basin** — ฝาง (แม่อาย, ไชยปราการ) | แอ่งหุบเขาทางเหนือที่มีการตั้งถิ่นฐานต่อเนื่อง; ขอบเขามีหลักฐานดินถล่ม STRONG ≈ 26% ของพื้นที่อำเภอ |
| เชียงใหม่ | **Ping valley south** — จอมทอง, ฮอด | แนวตั้งถิ่นฐานตามลำน้ำปิง; ฮอดมีถนนเชื่อมเพียง ≈ 41% ของพื้นที่ |
| เชียงใหม่ | **Western highlands** — แม่แจ่ม, อมก๋อย | ภูเขาและป่าที่เบาบาง (≈ 22 คน/km² ในแม่แจ่ม); สัดส่วน UNRESOLVED ของประชากรแบบจำลองสูงกว่าค่าเฉลี่ย (≈ 7% ในแม่แจ่ม) |
| เชียงราย | **Chiang Rai urban corridor** — เมืองเชียงราย | แกนเมืองหลักทางเหนือ; มีหลักฐานน้ำท่วม STRONG บางส่วน (≈ 7% ของพื้นที่อำเภอ) |
| เชียงราย | **Northern plain** — แม่สาย (แม่จัน) | ที่ราบชายแดนที่มีการตั้งถิ่นฐานหนาแน่น; หลักฐานน้ำท่วม STRONG ≈ 37% ของพื้นที่อำเภอ |
| เชียงราย | **Mae Suai corridor** — แม่สรวย | หุบเขาตามทางหลวงสายเชียงใหม่–เชียงราย; หลักฐานดินถล่ม STRONG ≈ 42% ของพื้นที่อำเภอ |
| เชียงราย | **Wiang Pa Pao valley** — เวียงป่าเป้า | หุบเขาแคบตามทางหลวง; ทั้งอำเภออยู่ในโซนออกแบบรับแรงแผ่นดินไหว |
| เชียงราย | **Phan plain** — พาน | ที่ราบลุ่มระหว่างเชียงรายกับพะเยา; หลักฐานน้ำท่วม STRONG ≈ 13% |
| เชียงราย | **Mekong edge** — เชียงของ | เมืองริมโขง; ปลายทางบริการ/สถานพยาบาลถูกจำกัดใน 3 จังหวัด ไม่มีปลายทางต่างประเทศ |
| พะเยา | **Phayao–Dok Kham Tai basin** — เมืองพะเยา, ดอกคำใต้ (แม่ใจ) | แอ่งกว๊านพะเยาและที่ราบดอกคำใต้; หลักฐานน้ำท่วม STRONG ≈ 15% ของพื้นที่ดอกคำใต้ |
| พะเยา | **Chiang Kham valley** — เชียงคำ | หุบเขาทางตะวันออกเฉียงเหนือของพะเยา; ไม่อยู่ในโซนออกแบบรับแรงแผ่นดินไหว |
| พะเยา | **Pong / eastern Phayao corridor** — ปง (เชียงม่วน) | การตั้งถิ่นฐานเบาบางตามหุบเขา (≈ 22 คน/km²); ถนนเชื่อมเพียง ≈ 31% ของพื้นที่ |

ไม่มีชื่อใดในตารางนี้ถูกจัดเป็น BEST / GOOD / BAD / RECOMMENDED
